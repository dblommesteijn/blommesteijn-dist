TerminalTerminal — mbat
 
The CLI the other three run. Commands that change the mode need root and re-run themselves through sudo.De CLI waar de andere drie op draaien. Commando's die de stand wijzigen hebben root nodig en starten zichzelf opnieuw via sudo.
 
 
 
 
 
 
Menu bar appMenubalk-app
 
Shows the charge and the power mode as a colour: purple High, yellow Low, plain Automatic. It runs the same commands as the terminal.Toont de lading en de stand als kleur: paars High, geel Low, neutraal Automatic. Hij voert dezelfde commando's uit als de terminal.
 
 
 
 
 
 
Control Center
 
A Battery control after Apple's own, on macOS 26 and later. Tapping it opens the mbatterier menu.Een Battery-bediening naar Apple's eigen voorbeeld, vanaf macOS 26. Tikken opent het mbatterier-menu.

InstallInstalleren
 
$ make install-system        # /usr/local/bin/mbatterier + mbat
$ make TEAM=<team ID> install-menulet
$ make install-agent         # optional: mbat watch at boot# optioneel: mbat watch bij het opstarten
 
No third-party Go modules or Python packages. The menu bar app is signed with your own Apple Development certificate; the README has the steps.Geen Go-modules of Python-pakketten van derden.
